# 空叶文档、空叶键盘、空叶悬浮球联动使用与手机测试

适用版本：空叶文档 **3.2**、空叶键盘 **2.0.3**、空叶悬浮球 **3.0.1**。

这三个软件共用空叶文档中的“密码空间”：文档负责保管，键盘负责输入时选择、生成和保存，悬浮球在你点击“填充密码”时读取当前页面并尝试填写。

## 1. 安装与开启（只做一次）

1. 从本次三个 GitHub Release 下载 APK，直接覆盖升级。键盘是 ARM64 版；悬浮球一般选 `arm64-v8a`，不确定时选 `all-universal`。
2. **空叶文档请覆盖安装，不要先卸载。** 卸载会删除本地数据和加密密钥。重要密码先在密码空间设置备份密码并做加密备份。
3. 打开空叶文档 →“文件”→ 切换到“密码空间”→ 顶部“密码填充”→ 打开“允许空叶键盘 / 悬浮球读取”。这里默认关闭，也能看两个软件是否安装。
4. 打开空叶键盘，在系统中启用它并切换为当前输入法；进入键盘设置 →“密码填充”→ 打开“密码填充”。“密码空间来源”选择 **正式版**。
5. 打开空叶悬浮球，按首页提示开启悬浮显示和无障碍权限，让球显示出来。在快捷菜单/边缘快捷功能中使用“填充密码”；如果没有看到，可在功能管理中添加“填充密码”，也可把一个手势绑定到它。
6. 手机要设置锁屏密码或可用的指纹。首次读取密码时由系统验证；成功后一般 5 分钟内可继续使用，锁屏立即失效。两个客户端共享文档的这段解锁有效期。

开启联动不等于后台自动登录。键盘需要你点候选，悬浮球需要你点“填充密码”；验证后也不会自动点击网页或 App 的“登录”。

## 2. 先准备两条测试密码

建议先用假数据，不必真的注册账号，也不要在不信任的网站试真实密码。

在空叶文档“密码空间”添加普通密码：

| 字段 | App 测试条目 | 网页测试条目 |
|---|---|---|
| 名称 | 测试登录 App | 测试网站 |
| 账号 | kongye_test | kongye_web |
| 密码 | TestOnly!Aa123 | WebOnly!Bb456 |
| 适用的 App | 选择你准备测试的普通 App | 留空，不选择浏览器 |
| 网址 | 可留空 | 填你将打开的测试登录页主机名，例如 `accounts.example.test`（示例域名需换成实际页面） |

“适用的 App”列表不会列出浏览器。网页凭网址区分，不能把所有网站共用关联到 Chrome 或其他浏览器。

## 3. 普通 App：用键盘填写已有账号

1. 打开已关联 App 的登录页，点击账号输入框，确认弹出的是空叶键盘。
2. 在候选栏点“🔑 条目名称 · 打码账号”。尚未解锁时按提示验证；回到原输入框后重试即可。
3. 账号填入后，键盘会尝试跳到普通密码框并继续填写。若页面没有正确跳转，手动点密码框，再点条目候选。
4. 没推荐出来时，点“🔍 搜索密码空间”，搜索条目名称或账号后选择。
5. 普通 App 中通过搜索选中并填充条目，会把该 App 关联到条目，之后可直接推荐。

账号后的自动续填只进入**普通密码框**，不会自动把已有密码放进“新密码”“确认密码”或“验证码”框。页面不规范时可能需要分两次选择。

## 4. 注册：生成密码并存入文档

1. 在注册页填写账号，再点提示为“新密码”“设置密码”的输入框。
2. 候选栏出现“生成强密码”时点击，密码会填进当前输入框。
3. 到“确认密码”框，点“使用刚生成的密码”。该复用只限同一 App，两分钟内有效。
4. 完成输入或按键盘回车后，留意候选栏的保存提示；必要时点回输入框展开键盘。
5. 点“存到空叶文档？”才会真正保存，再回文档核对条目。

若注册页没有标出新密码，生成按钮可能不出现。可直接在空叶文档添加密码，用密码旁的“随机生成密码”按钮生成并先保存，再通过搜索填入注册页。

保存提示以键盘的输入/提交事件触发，不保证能识别网页实际注册成功。看到提示时应及时确认：待保存内容约 30 秒有效，切换到其他 App、锁屏、点“不保存”或关闭提示会清除暂存。不要还没保存就离开当前 App。

## 5. 浏览器：键盘填写与保存

### 已有网页账号

1. 打开登录页面，点击账号或密码框。
2. 用键盘的“搜索密码空间”搜索网站条目并选择。
3. 账号和密码没有连续填完时，手动点相应输入框再选择一次。

键盘不知道浏览器当前地址，因此**不按浏览器包名自动推荐，也不会把所选条目绑定到整个浏览器**。每次选择前核对当前网站地址和条目。

### 网页注册的新密码

1. 按上一节生成、确认密码。
2. 点击“**存到空叶文档（需补网址）？**”。网页里仍会保留这个保存入口。
3. 文档里会新增类似“Chrome 网页密码（请补网址）”的条目。
4. 确认保存成功后，再到文档编辑条目，改成清楚的网站名称，并补上实际登录页的网址；“适用的 App”留空。

由于键盘拿不到网址，这个入口**每次新建，不会更新原有网站条目**。同一个网页重复保存后可能有多个条目，核实最新有效密码后再自行整理，避免把其他网站的同名账号覆盖。

## 6. 用悬浮球填充 App 或网页

1. 先把目标登录页打开，页面上应能看到标准账号框和密码框。
2. 点悬浮球菜单里的“填充密码”（或已绑定的手势）。
3. 有匹配时选择条目；没有匹配时，在弹出的列表中搜索名称/账号。
4. 如提示解锁，完成系统验证并返回原登录页，保持页面及输入框不变。
5. 悬浮球会尝试把账号和密码写入输入框；你核对后再自行点登录。

普通 App 主要按 App 关联推荐。支持的浏览器若能读取地址栏，则按网址推荐，传给文档的是网址，不同时传浏览器包名；读不到网址时可手动搜索选择，文档仍不会把浏览器当作条目的适用 App。

悬浮球目前侧重**读取并填充已有密码**，生成和保存新密码请用键盘/文档。只在你触发时尝试读取页面，不会在后台主动填写。网站自绘输入框、安全键盘、网页嵌套等可能不支持，填不进去时也不会把密码偷偷放到剪贴板。

## 7. 手机测试清单

先用假账号测试，不需要点真实“登录/注册”按钮，也不要拿真实账号试错。

| 测试 | 操作 | 预期 |
|---|---|---|
| App 推荐 | 给测试条目关联一个普通 App，再点它的登录框 | 键盘出现条目候选；可搜索填充 |
| 首次解锁 | 在文档的密码填充页点“立即锁定”，再选择密码 | 出现系统验证；取消不应填入 |
| 注册生成 | 新密码框生成，再到确认框复用 | 两次填入相同密码；可显式保存 |
| 网页不误关联 | 浏览器登录框中搜索并选择条目 | 条目不会新增 Chrome/其他浏览器关联 |
| 网页不误覆盖 | 浏览器里用同一个测试账号，分别手动完整输入两次不同假密码，并分别保存 | 文档新增两条，不把第一条覆盖；保存提示提醒补网址 |
| 旧密码保留 | 在同一个普通 App 用同一个测试账号完整输入假密码并保存，再清空密码框后完整输入另一个假密码并保存 | 更新同一条；编辑条目可见以“旧密码”开头的隐藏字段，内容是上一次密码 |
| 历史限额 | 在上一测试里继续用不同假密码更新几次 | 最多保留最近 3 个旧密码；重复保存相同密码不增加历史 |
| 网页悬浮填充 | 给测试条目补上实际网站网址，在支持的浏览器登录页触发“填充密码” | 能读到地址栏时按网址推荐并填充；不关联整个浏览器 |
| 锁屏失效 | 已解锁后锁屏、解锁手机，再选密码 | 再次要求验证 |
| 关闭联动 | 关闭文档中的读取开关，再尝试填充 | 客户端提示未开启/不可用，不读出密码 |

旧密码保留目前针对**键盘通过保存接口更新已有条目**，不是在文档编辑页手动改密码的通用版本历史。测试更新时账号必须相同，且是同一个普通 App；从键盘粘贴密码、修改已有密码的一小段，不会被当作完整密码记录。

“密码/验证码”混合提示框：如果页面把它声明为密码类型，键盘仍关闭学习、剪贴板、复制与语音等敏感功能，但不自动填密码、也不提示保存验证码。这个测试需要页面确实提供对应的输入类型和提示，仅把普通文本框标题改成“验证码”不能等价验证。

网页保存的后端规则还包括：相同账号、规范化主机名完全相同才更新；`a.example.com` 与 `b.example.com` 分别新建。键盘目前拿不到网址，所以日常网页保存走“新建后补网址”，而不是按网址更新。网页候选推荐仍沿用原有子域名规则，选择前核对地址。

## 8. 没反应时按这个顺序查

- **键盘没有候选**：确认当前输入法是空叶键盘；文档和键盘的两个开关均开启；键盘来源选“正式版”；尝试搜索。提示为验证码的框不出现填充入口是预期行为。
- **密码框突然换成系统键盘**：可能启用了手机的“安全键盘”。如要测试第三方键盘填充，可在系统设置中调整该项。
- **提示拒绝访问**：三个软件必须同签名。用本次 Release 的配套安装包；更早的旧签名悬浮球可能不能直接覆盖安装。先核对，尤其不要为解决签名问题卸载文档。
- **指纹面板没出现/取消后没填**：返回原登录页，重新选择条目或重新触发“填充密码”，核对手机锁屏验证是否可用。仍失败时记录手机型号、系统版本、操作步骤和提示；本次完整 UI 回归也遇到过系统面板未显示，不能承诺所有机型都成功。
- **提示“这里填不了”或页面已改变**：保持登录页不切换、不滚动到另一页，重新点输入框再触发；自绘安全控件不保证支持。
- **没看到保存提示**：必须是空密码框中由键盘完整输入/生成的密码；粘贴、移动光标、修改局部内容会放弃捕获。提示只短暂保留，切换 App 或锁屏会清掉。
- **想确认是否调用成功**：文档 → 密码空间 → 密码填充 → 最近访问，可看调用方、目标、方法与结果。日志不会记录账号密码明文。

测试完成后，把测试条目删除即可。正式密码继续留在空叶文档的密码空间，并定期检查加密备份可恢复。
