# 3.7.3 密码统计紧凑排版

日期：2026-11-22。基于 3.7.2，版本 3.7.3 / 70。

- 将原有大号数字统计区域改为两行紧凑排版：首行「密码总数」与右对齐总数，下面通过细分隔线与三个横向分类数量区分。
- 分类名称与数字同一行，使用 13 sp；总数使用 16/17 sp。减少空白，与备份、填充设置行保持一致。
- 数量计算、收藏归类、分类滑动、备份及填充操作保持原有逻辑。
- 按用户补充要求，收藏条目的左侧钥匙或盾牌改为收藏图标，移除名称右侧额外的五角星。
- 尚未设置备份密码时，密码空间列表（含空列表）显示轻提示，可直接进入设置；配置后消失，清空配置后重新显示。

通过指定 Android Build Shell 运行 assembleDebug、assembleDebugAndroidTest、assembleRelease；最终日志位于 `build/verification/vault373/onboarding-build.log`。

在小米 17 / 77079774 使用独立测试包与虚构数据复用 new-vault-ui 检查，包含总数与分类数、收藏图标在名称左侧、收藏移入移出、横滑边界、字母索引和设置入口；同时检查未配置提示、提示跳转和配置后消失。真机截图及结果位于 `build/verification/vault373/`。正式安装包 `build/verification/KongyeDocs-3.7.3.apk`，通过 install -r 保留数据覆盖安装。
