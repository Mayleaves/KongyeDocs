# 3.7.1 密码空间布局

日期：2026-11-22。基于 3.7.0，版本号 3.7.1 / 68。

- 列表移除普通密码掩码、显示密码按钮和逐条更多按钮。保留名称、账号、动态图标和验证码倒计时；详情内仍可查看和复制密码，长按条目保留置顶、编辑、复制全部及删除操作。
- 顶部改为三个筛选分类：置顶、动态密码、普通密码。默认普通密码。置顶显示两种类型的置顶条目，其他分类按类型显示（含该类型的置顶条目）。数量仍显示密码空间总数；字母索引依据当前分类跳转。
- 原来的备份设置移入「我的」数据安全组，名称为「密码备份」，用于区分已有本地备份和云端备份。原来的设置、修改备份密码及停用入口保留。密码填充也移入同组。
- 保留 3.7.0 波浪字母索引、滑动时隐藏加号、加号原位和多设备同步。

构建通过指定 Android Build Shell 启动。日志、真机测试结果、截图和签名安装记录在 `build/verification/vault371/`。正式 APK 位于 `build/verification/KongyeDocs-3.7.1.apk`。

小米 17（77079774）使用独立测试包与虚构数据验证分类、列表按钮移除、点击详情、长按菜单、索引动画与加号，以及「我的」内两个入口。原有自动保存字段编辑用例一并验证。没有清除正式应用数据。
