# 3.7.4 密码保存页

日期：2026-11-22。基于 3.7.3，版本 3.7.4 / 71。

## 修改

- 保存页采用账号信息卡片，将名称、账号、密码集中显示；字段名与内容不再重复铺开。
- 附加字段使用统一卡片，可勾选、修改名称和内容、移除，仍可添加字段。
- 标题增加钥匙图标，背景变暗；字段区独立滚动，保存与不保存按钮固定在底部。
- 打开确认页不自动弹出键盘，点击可编辑字段再输入；浅色、深色使用应用统一配色。
- 仅在独立测试的虚构数据截图期间临时清除 FLAG_SECURE，截图后立即恢复；正式页面保留禁止截屏。

## 验证与交付

按指定 Android Build Shell 构建 debug、androidTest 和 release，使用 E 盘缓存及临时目录。最终日志与签名、安装、GitHub 回读校验记录位于 `build/verification/save374/`。

小米 17 / 77079774，独立测试包 com.kongye.docs.audit，执行 save-preview。真实点击改名账号、密码和邮箱字段，新增字段及内容后保存，检查保存值一致。确认初始键盘隐藏；浅色、深色和新增字段截图位于 `build/verification/save-preview/screenshots/`，已给用户查看。

正式包 `build/verification/KongyeDocs-3.7.4.apk`，与既有版本同签名，使用 install -r 覆盖安装，不清除密码和文档。
