# 3.7.5 密码空间排序

日期：2026-11-22。基于 3.7.4，版本 3.7.5 / 72。

- 排序入口位于分类数量同一行的右侧，仅文字与小下箭头；云同步状态有独立位置，长状态限制宽度并省略，不挤占排序入口。
- 三种排序：字母排序默认 A–Z / #；按增加时间从新到旧；按修改时间从新到旧。中文按拼音归类，数字与符号归 #；时间相同时按名称和稳定 ID 排序。
- 记忆在本机设置 vaultSortMode，旧安装默认字母排序；对收藏、动态密码和普通密码分类生效。
- 字母模式保留字母分组及波浪索引；时间模式使用连续列表并收起字母索引。切换排序返回列表顶部。

构建使用指定 Android Build Shell、E 盘缓存与临时目录，执行 assembleDebug、assembleDebugAndroidTest、assembleRelease。最终日志 `build/verification/vault375/final-build.log`，安装记录位于同目录。
