# 3.7.0 同步与密码空间验证

日期：2026-11-22。基于 3.6.0；版本 3.7.0 / 67。

## 实现范围

- WebDAV 的 `KongyeDocs/sync-v1` 保存每个安装实例独立的加密检查点。密码、文件夹、文档格式、图片和回收站状态参与同步；普通备份仍保留。
- 使用逐条记录的向量时钟、并发版本和删除标记。独立条目的修改合并，同条目的并发修改保留双方版本，可查看并选择采用版本；选择结果向其他设备传播。
- 数据和本机同步状态通过同一 DurableFiles 事务落盘。上传后完整回读校验，失败保留修改；同步设备身份排除 Android 自动备份和设备迁移。
- 打开应用、修改内容和系统后台任务触发同步。未改变的数据不重复上传；正在编辑的文档延后替换，替换之前保存本地文档版本。
- 密码空间显示数量，提供 ☆ / A–Z / # 滑动索引，中文按拼音归类。手指附近字母形成波浪，当前字母圆点跟随手指，松手恢复；侧栏留出系统返回手势区域。
- 「+」保持原有右侧 20 dp、底部 20 dp 位置，滑动索引时暂时隐藏，结束后恢复。
- 自动保存页支持账号和密码字段改名、其他字段改名及编辑内容、添加自定义字段。自动填充仍使用稳定的账号和密码数据字段。
- 未固定工具面板时，选择段落格式、标题、文字样式或颜色后返回键盘；明确固定面板时保留批量调整方式。

## 使用边界

- 两台手机均需安装新版、填写相同 WebDAV 地址和账号、使用相同备份加密密码，并在「云端备份 → 多设备同步」开启「同步密码和文档」。默认关闭，不替用户启用真实云端写入。
- 初次开启会合并各设备现有内容；旧格式备份文件继续通过原来的恢复入口读取，不会自动覆盖本机。
- 测试的两个设备状态为小米上一组完全独立数据目录，共用受控 WebDAV 测试服务器；没有宣称已在两部物理手机或用户坚果云账户完成互传。
- 单份同步文件上限 64 MB，超限显示错误并保留本机数据；不属于逐字实时协同编辑。
