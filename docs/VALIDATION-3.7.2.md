# 3.7.2 收藏分类与设置导航

日期：2026-11-22，基于 3.7.1，版本 3.7.2 / 69。

## 改动

- 「我的」仅保留「密码空间」入口，进入后显示密码备份、密码填充。两项设置的既有操作继续保留。
- 密码空间中置顶改为收藏，菜单文案为「收藏 / 取消收藏」，行内图钉改为收藏图标。
- 沿用既有 pinnedAt 数据表示收藏，旧置顶和云同步数据无需重写或重新创建；旧置顶自动出现在收藏分类。
- 收藏同时容纳普通密码与动态密码，另外两个类型分类只显示未收藏条目。取消收藏后回到原类型。
- 文件页外层 pager 禁止触摸滑动，仅点击顶部切换桌面和密码空间。密码空间内部使用独立 pager 切换收藏、动态密码、普通密码；到达边界不会进入桌面。
- 字母索引统一按名称归类，移除 ☆，保留 A–Z、#、波浪动画以及滑动时隐藏加号。
- 数量显示当前分类下的条目数；收藏数包含两种密码，动态密码分类显示动态密码数量。
- 「我的 → 密码空间」展示总数及三个分类数，收藏从两个类型分类剔除，因此三个分类数之和等于总数。
