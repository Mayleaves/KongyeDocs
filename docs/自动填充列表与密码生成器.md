# 自动填充列表与可选密码生成器（3.4.3）

- 系统自动填充列表改为清爽底色、应用图标、细分隔线与独立的“更多密码”入口，深色模式使用对应配色。最外层边框、圆角、阴影由 Android 系统绘制。
- 更多密码与生成密码页面关闭窗口过渡和背景遮罩，进入时聚焦搜索/密码输入并保持键盘显示；直接选择账号时避免窗口抢占输入焦点。
- 页面识别到的长度范围与实际生成的长度分开显示，例如“页面长度：8–20 位”和“长度：16 字符”，不再混为同一个要求。
- 生成器支持 4–64 位整数滑条及大写、小写、2–9 数字、指定特殊符号、易混字符五个独立开关。默认排除 10iolIOL，选中时才加入；每个选中类别至少出现一次。
- 全部取消或长度少于选中的类别数时提示重新选择；与页面范围不同时提示核对实际要求，仍可按手动选择填入。
- 密码使用 SecureRandom；明文不写入配置或 Activity 恢复状态，保留安全窗口标志。

验证：独立测试版上生成器各字符组合与长度检查通过；“更多密码”和生成页面检测到输入法窗口保持可见。系统下拉框仍需在具体目标 App 中核对最终显示及切换体验。
